# 订单物流延迟与包裹异常处理手册

## 适用场景

本指引用于处理用户反馈的订单未发货、物流长时间不更新、包裹运输延迟、配送地址异常、显示已签收但未收到、包裹破损或少件等问题。客服需要先确认订单状态和物流节点，再向用户说明当前可执行的处理方案。不得在未核实订单状态前承诺补偿、退款或重新发货。

## 一、收集信息与基础核验

用户咨询物流问题时，先确认订单号、下单时间、收件人手机号后四位、商品名称和用户当前看到的物流状态。若用户无法提供订单号，可使用手机号后四位、下单日期和商品名称协助定位，但不得要求用户在聊天中发送完整身份证号、银行卡号、支付密码或短信验证码。

核验后重点检查以下信息：订单是否已经支付成功；仓库是否已完成出库；物流单号是否已生成；首条揽收记录的时间；最近一条物流轨迹；是否存在地址拦截、超区配送、天气影响、节假日积压或系统同步延迟等标记。对于预售商品、定制商品或跨境商品，还应查看商品详情页或订单页显示的预计发货周期。

## 二、不同订单状态的处理方式

### 1. 已支付但未发货

如果仍在商品承诺发货时效内，向用户说明订单正在备货或等待仓库出库，并告知预计发货时间以订单页面为准。建议用户关注订单状态，不要重复提交相同催发货申请。若已超过承诺发货时效，应创建工单，记录订单号、超时天数、商品名称和用户诉求，转交订单或仓储支持人员处理。

### 2. 已发货但未揽收

部分物流公司会在商家交运后数小时同步首条揽收记录。若发货后不足二十四小时，可请用户耐心等待并在稍后刷新物流页面；若超过二十四小时仍无揽收信息，记录物流单号和发货时间，创建物流异常工单，要求仓储或物流方核查包裹是否实际交接。

### 3. 运输中长时间不更新

同城或普通快递在二十四小时内没有轨迹变化不一定异常，跨省、偏远地区、恶劣天气、节假日高峰期间的更新时间可能更长。客服应依据承运商和目的地判断。若最后一条轨迹超过四十八小时没有更新，且没有天气、节假日或超区说明，可建议用户等待一个工作日，同时登记异常工单。工单中应包含最后物流节点、最后更新时间、承运商、目的地省市和用户是否急用。

### 4. 显示地址异常、派送失败或联系不上收件人

提醒用户核对收货地址、联系电话和门牌信息是否完整。用户确认信息正确时，可建议其联系承运商安排二次派送；若订单系统支持修改地址，必须先确认包裹尚未进入派送环节。对于已经退回或即将退回的包裹，客服不能擅自承诺拦截成功，应创建工单由物流团队确认后续是重新派送、退回后退款还是重新发货。

### 5. 显示已签收但用户未收到

先确认签收时间、签收方式和签收地点，建议用户询问家人、物业、前台、邻居或快递驿站，并查看是否存在代收记录。若二十四小时内仍未找到包裹，立即创建“签收未收到”工单，附上订单号、物流单号、签收时间、用户已核查的地点和联系电话后四位。该场景可能涉及承运商举证或理赔，不能直接认定丢件。

### 6. 包裹破损、少件或收到错误商品

请用户保留外包装、面单、商品和开箱照片，不要急于丢弃包装或自行寄回。客服应记录受损商品名称、数量、外箱状态和照片是否齐全，并按售后规则创建工单。若用户提出退款或补发，先说明会在核验订单和凭证后处理，避免给出未经批准的结论。

## 三、沟通规范

回复应先表达理解，再说明已核验到的节点和下一步动作。不要使用“肯定今天送达”“一定能追回”等绝对性措辞。对于可以自助查询的情况，给出清晰路径；对于需要人工处理的情况，说明已记录并将由相关团队核查，但不承诺具体完成时间。

## 四、客服回复示例

您好，已帮您查看到订单目前处于运输中，最近一条物流记录为“转运中心发出”。运输轨迹可能受承运商中转、天气或节假日影响而延迟更新。建议您先等待一个工作日并关注物流信息；如超过四十八小时仍未更新，我可以为您登记物流异常，由相关团队进一步核查。

若订单显示已签收但您未收到，建议您先向家人、物业、前台和附近驿站确认是否代收。若确认仍未找到，请告诉我订单号和签收时间，我会为您创建核查工单。请放心，在核查完成前无需提供支付密码或验证码。
