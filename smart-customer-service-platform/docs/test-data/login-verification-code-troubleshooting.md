# 登录收不到验证码处理指引

## 适用场景

用户在注册、登录、修改手机号或进行安全验证时，长时间未收到短信验证码。

## 排查步骤

1. 请用户确认填写的手机号是否正确，并确认该号码能够正常接收其他短信。
2. 提醒用户检查短信收件箱、垃圾短信或系统拦截记录，部分手机安全软件会拦截验证码短信。
3. 建议用户等待 60 秒后再重新获取验证码。短时间内连续请求会触发频率限制，旧验证码也会随新验证码失效。
4. 若用户使用境外号码、虚拟运营商号码，或当前网络信号较弱，短信可能出现延迟或无法送达。
5. 建议用户切换网络、重启手机后再次尝试；仍无法解决时，记录手机号后四位、操作时间和业务场景，转人工客服进一步处理。

## 客服回复示例

您好，请先核对手机号是否填写正确，并查看垃圾短信或短信拦截记录。验证码发送后请等待约 60 秒再尝试重新获取，避免频繁点击导致触发发送限制。若仍未收到，请提供操作时间、业务场景和手机号后四位，我们会继续协助排查。

## 注意事项

- 不得向用户索取完整验证码、密码或身份证号码。
- 不要承诺具体恢复时间；如需人工处理，应说明将继续核查短信通道和账号状态。
