# 智能客服与工单自动化平台前端

独立 Vue 3 + Vite 前端项目，对接后端 `/api/v1` 接口。

## 启动

```bash
npm install
npm run dev
```

默认后端地址通过 `.env` 配置：

```bash
VITE_API_BASE_URL=http://localhost:8080
```

## 已封装接口

- 认证：注册、登录、刷新 Token、退出登录、当前用户、当前菜单
- 客户：创建、分页、详情、更新、删除
- 会话：创建、详情、消息历史、发送消息
- AI：问答、生成工单草稿
- 工单：创建、分页、详情、派单、关闭
- 派单规则：创建、分页、详情、更新、删除
- 知识库：检索、文章创建、分页、发布、下线
- 统计看板：运营指标
